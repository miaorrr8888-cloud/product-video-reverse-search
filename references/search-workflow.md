# 取得候选的三条路线

1. 宿主有网页搜索工具时，以品牌、型号和 review/demo 等用途检索公开视频页面，把实际返回的标题与URL填入候选。没有核验的内容、播放量和同款身份保留未知。examples/live-search-candidates.json 是实际公开检索返回的两个标题和URL，不是内容观看或同款核验结果。
2. 需要图片参考时，先从参考图列出可见外观特征，再用宿主图片搜索获取候选页面；这属于图片辅助的关键词检索，不是上传原图的像素反搜。记录结果页URL和未知项，不把相似商品写成同款。私有图片不得因这一流程自动上传第三方。
3. 已有授权取得的本地图片时，运行 search_local_images.py；若需要官方YouTube API，使用 search_youtube.py 的显式 --live 模式并自行配置权限和额度。当前官方API路线没有真实账号实测。

本地图片排名的形状哈希和颜色直方图属于简单启发式；分数不代表视觉身份概率。来源许可、真实型号与复用权需独立确认。
